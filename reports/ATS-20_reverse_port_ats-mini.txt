ATS-20 reverse-port: ats-mini → ATmega328P
Идея финальной полировки. Не текущий код. Ветка ATS-20Plus_next.

Три опоры, разные роли. Не смешивать.

  Goshante ATS_EX v1.18     эталонная контрольная точка
        │                   «как должен ощущаться ATS-20 в руках»
        │                   latency, кнопки, SSB BFO, без ESP32-роскоши
        ▼
  diqezit/ats20_ats_ex      текущая основа железа ATS-20 / ATS-20+
        │                   сервис (ANB, SQL, DIS, CWP, NACK/STOP), не UI
        ▼
  esp32-si4732/ats-mini     только архитектурные идеи
                            не скетч, не TFT, не Wi-Fi

Мы уже не на чистом Goshante: Sweet Spot, radio.cpp, MENU RADIO/DISP/AUDIO/SYS.
Полировка = сжать хорошие идеи Mini в 328P, сверяя с v1.18, чтобы не превратить
приёмник в «маленький ESP без памяти».

------------------------------------------------------------------------
Reverse-port (единственный допустимый вектор)

  ESP32-S3 implementation
           ↓
  identify good architecture
           ↓
  remove unnecessary abstraction
           ↓
  static data structures
           ↓
  zero / low allocation
           ↓
  event-driven
           ↓
  ATmega328P

Не заставлять 328P делать то, что делает ESP32.
Вытащить только идеи, которые стоят своих байтов (~578 B запаса на момент MENU).

ats-mini (github.com/esp32-si4732/ats-mini) сам честно стоит на Goshante + G8PTN
+ PU2CLR + Ralph Xavier. Круг замыкается: Mini — младший брат с цветным TFT,
не чужая планета.

------------------------------------------------------------------------
1. Goshante v1.18 — контрольная точка

Зачем: регресс «ощущения». Если полировка ухудшает крутилку, seek или SSB
относительно v1.18 — идея из Mini не стоит байтов.

Смотреть в v1.18 не исходник как цель (delay в loop, полный RDS, частота в
цикле focus), а контракт:

  encoder не ждёт OLED/RSSI;
  SSB = BFO + wrap kHz, без «чфа» на каждом герце если можно coalesce;
  кнопки MODE/STEP/BAND/VOL делают одно очевидное;
  экран 128×64 SSD1306, не спрайт 320×170.

Наш firmware_analysis.txt уже зафиксировал болезни v1.18. Эталон = руки, не баги.

------------------------------------------------------------------------
2. diqezit — основа железа, не UI

Уже взяли по одной + avr-size: шаги AM/SSB, ANB, SQL, DIS, CWP.
Не брать: Pong, Active Command, GyverOLED, полный RDS, класс Radio.

Ещё стоит байтов с их стороны (когда дойдём), ортогонально Mini:

  NACK → STOP на I2C (microWire / SI4735-fixed);
  не разгон шины в покое.

------------------------------------------------------------------------
3. Что в ats-mini выглядит как архитектура (не фичи)

Файлы Mini (ориентир, не копировать):
  Common.h     режим, Band, currentCmd
  Menu.h/.cpp  CMD_* : operational menu vs SETTINGS
  Draw.h/.cpp  layout, не радио
  Layout-*     смена плотности MAIN
  SI4735-fixed патч библиотеки, не «ещё один SI4735.cpp»

Идеи, которые сжимаются:

A. Один контекст энкодера
   Mini: currentCmd (FREQ / STEP / VOLUME / MENU / SETTINGS/…).
   У нас: куча bool g_cmd* + g_uiFocus + g_menuLevel.
   Сжать в один uint8_t/uint16_t command — возможно дешевле flash, чем шесть
   флагов. Не класс CommandDispatcher.

B. Operational vs configuration
   Mini: isMenuMode vs isSettingsMode (CMD_BAND… vs CMD_BRT…).
   У нас уже: MAIN transients (STEP/VOL/BFO/BW) vs MENU категории.
   Не тащить sidebar/zoomMenu/TFT sprite. Иерархия 2 уровня достаточна.

C. Draw отделён от Si473x
   Mini: drawFrequency / drawSMeter / drawLayout*.
   У нас: showFrequency / showSMeter / uiFlush + dirty bits.
   Усилить: layout как таблица регионов (page 5 S-meter), не спрайт.
   См. ATS-20_S-meter_dirty.txt.

D. updateFrequency / updateBFO как единственная точка wrap
   Mini: bool updateFrequency(int, wrap), updateBFO.
   У нас размазано doFrequencyTune / doFrequencyTuneSSB / clampSSBBand.
   Сжать осторожно: LTO и так inlines; новый слой легко +200 B.

E. clickHandler(cmd, shortPress)
   Событие, не простыня loop(). На 328P: маленькая таблица (cmd, press) →
   функция, без virtual. Только если loop() снова распухнет.

F. NACK/STOP
   Не Mini SI4735-fixed скопом. waitToSend() сейчас крутит requestFrom до CTS
   без потолка. Исследование: ATS-20_I2C_nack_stop.txt.

Идеи Mini, которые НЕ стоят байтов на ATS-20:

  TFT_eSprite / themes / zoom / scroll UI
  Wi-Fi, NTP, BLE HID, USB remote, EIBI, scan-графики
  99 memories, Preferences вместо EEPROM
  два полных layout как отдельные .cpp (Layout-Default + SMeter)
  sleep ESP32 light-sleep
  per-band usbCal+lsbCal в Band, пока EEPROM и так 123

Digit-select частоты (doSelectDigit) — спорно: на 7-seg может быть дорого
и ломает «rotate = частота». Отложить.

------------------------------------------------------------------------
4. Очередь (согласовано)

1. NACK/STOP — изолированно. ATS-20_I2C_nack_stop.txt.
   Не стек Mini. Критерий: четыре замера; audio glitch = откат.
2. currentCmd — один uint8_t вместо роя g_cmd*. Только если avr-size
   Flash+SRAM до/после лучше или не хуже. Без субъективных «стало чище».
3. Draw ↔ Si473x — граница функций, не framework:
     radio_update / commit  не рисует экран;
     ui_draw_*              не ходит на Si473x.
   Уже почти так (radio.cpp vs show*). Довести, без DisplayManager.
4. operational vs config — решено: APP → MAIN | MENU + transient/editing.
   Не импортировать Mini currentCmd-меню как систему контекстов.

Acceleration 10/100/1k — слух SSB, отдельно от этой очереди.

------------------------------------------------------------------------
5. Чего не делаем (класс продукта, не полировка)

sprite; themes; Wi-Fi; BLE; EiBi; огромная memory/config;
scanner graphics; ESP32 light sleep; TFT-oriented rendering.
Класс Radio / EventBus / Renderer.

Не сверять успех с Mini на цветном экране.
Не забывать v1.18: крутилка и SSB в руках.
