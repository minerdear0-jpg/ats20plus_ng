ATS-20Plus_next — gap list (срез архива, не старый backlog)
Baseline прошивки: 4fe59be. Проверено grep по HEAD после 1482ce9 (доки).

Главный риск не «ещё функций», а граница:

  MCU timing  ↔  I²C  ↔  SI4732  ↔  UI latency

------------------------------------------------------------------------
P0  unbounded SI473x transaction latency

Цель не «сделать NACK/STOP», а: ни одна SI473x-транзакция не ждёт бесконечно.
NACK→STOP — кандидат способа. Спека: ATS-20_I2C_nack_stop.txt.
waitToSend() в PU2CLR SI4735.cpp: requestFrom до CTS без потолка.
ERROR UI не делать в этом эксперименте: сначала доказать, что сбой
вообще виден без раздувания библиотеки.

P0.5  CLKPR = 50% vs compiled F_CPU = 16 MHz

doCPUSpeed / CLKPR: 0 = 100%, 1 = 50% (16→8 MHz). Arduino TWI, millis,
delayMicroseconds, encoder/button, RF_COMMIT_MS 10, FREQ_COMMIT_MS 70,
timeout 1.2 s считаются от F_CPU компиляции.
На железе: реальный millis, фактический I²C, кнопки, burst, deadlines.
Не удалять CPU 50% превентивно. Сразу после bounded wait.

P1  мёртвый g_sMeterOn

bool g_sMeterOn = false; нигде не ставится true. Ветки в showStep /
showCharge / resetLowerLine / bandSwitch / switchCommand — мёртвые.
Удалить + avr-size. Обычно Flash не растёт.

P1  switchCommand prev / prevFunc

static bool* prev и void (*prevFunc)() только пишутся и обнуляются,
нигде не читаются для restore. Удалить если grep подтверждает (HEAD: да).

P1  currentCmd

Только после dead-state cleanup. Четыре g_cmd*, не MENU, не обязательно
убивать g_uiFocus. avr-size до/после; нуль/минус = выбросить.

P2  первый battery sample = 0%

showCharge: при forceShow берёт averageSamples (старт 0), рисует, потом
averageSamples = sample. Первый splash/status — 0%, живое значение через 10 с.
Почти бесплатно: sample → average → display.

P2  ERROR / retry UI

Спека есть, кода нет. Минимум после bounded I²C: g_radioError → MAIN
"RADIO ERR" → press → retry. Не сейчас.

P2  S-meter «dirty»

Зафиксировать: dirty-region (page 5), не dirty-pixel. При смене val —
полный ramp 114 колонок. Дешево и предсказуемо. Не чинить. Freeze.
Idle FM: GET RSSI + getCurrentPilot — не одна транзакция. Оставить.
SQL: handleSquelch(rssi) в showSMeter; doSQL → applySquelchNow — лишний
quality request. Не проблема, не трогать.
Battery analogRead в showCharge есть, но на encoder burst не доходим. Ок.

P3  MODE/BAND transient

Спека TRANSIENT_MODE / TRANSIENT_BAND. Код: MODE сразу applyBandConfiguration;
BAND — command toggle. Оставить: ощущение v1.18 важнее.

P3  две secondary rows

Спека page 6+7. Код: одна логическая secondary (UI_PAGE_SECONDARY = 6,
oledClearLine чистит y и y+1). Sweet Spot v0.1 неполный. Оставить.

DROP  Mini GUI/system; acceleration без слуха; framebuffer; DRY tune SSB.
