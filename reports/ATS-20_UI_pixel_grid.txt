ATS-20 UI — карта 128×64 (после сдвига FREQ→SIGNAL)

OLED: 128×64, 8 страниц × 8 px. UI-шрифт 8×16 = 2 страницы. 7-seg 14×24 = 3 страницы.

Порядок Sweet Spot: MODE → FREQUENCY → SIGNAL → secondary.

SSB idle (NORMAL)
page 0-1: MODE (+ Sync S)  BFO            VOL
page 2-4: 7-seg частота
page 5:   пусто (зазор под 7-seg)
page 6-7: S n[+] и 16px ramp. Нет St:, BAND, %

FM idle
page 0-1: FM  AUTO/BW   ST   VOL
page 6-7: S-meter 16px
STEP только transient (кнопка STEP). BAND только overlay.

FM idle (NORMAL)
page 0-1: FM              ST                  VOL nn   (+ BW если не в transient)
page 2-4: 7-seg MHz
page 5:   S n [+] ramp (Karat 5x7)
page 6-7: RDS PS/RT по умолчанию; MODE снимает RDS и показывает STEP/BAND

FOCUS
STEP/VOL/BFO: invert в своём слоте; частота и S-метр на месте.

TRANSIENT
page 0-1: инверт TITLE…………VALUE
page 2-7: без полной перерисовки

AM
как SSB без BFO; заряд % справа на page 6 если не SSB.
