ATS-20Plus_next — журнал

Ветка: ATS-20Plus_next (локально, без push).
Железо цели: Arduino Uno, ATmega328P, 32256 flash / 2048 SRAM.
I2C в рантайме: 100 kHz (I2C_RUN_HZ). Кандидат 400 kHz — ждать подтверждения на плате. Патч SSB по-прежнему 500 kHz.

Опора: три файла спецификаций в этом каталоге. UI — Sweet Spot.

Сделано
- Encoder burst, ISR короткий, loop: input first.
- Deferred SI4735 (70 ms), в том числе SSB BFO / kHz wrap.
- Нет delay() на крутилке и в seek-колбэке.
- RDS / S-метр / заряд не ходят по I2C, пока крутится encoder.
- Dirty mark/flush для частоты.
- Слои UI_LAYER_NORMAL / FOCUS / TRANSIENT.
- Клик энкодера: частота → STEP → VOL → BFO (SSB) → частота.
- Поворот focused control: залитая верхняя полоса 16×128 (paintTransient).
- Timeout 1.5 с → idle header.
- Seek AM/FM: длинное нажатие энкодера (короткое больше не seek).
- S-метр постоянно на OLED page 2 (не перекрывает STEP).
- Splash v1.19, соавторы OOMAN and Cursor.

Компромиссы относительно Sweet Spot
- Нет второй строки secondary (BFO+VOL как на макете): VOL на page 0, STEP на page 6.
- Нет pixel-perfect сетки всех экранов.
- Меню configuration без иерархии (старые SETTINGS).
- FOCUS_BFO: заливка на idle-слоте +450, transient при повороте.
- На SSB idle справа на page 6 спокойный BFO; заряд % там не рисуется (VOL сверху).

Компромиссы относительно Sweet Spot
- Нет второй полной строки secondary как на макете 128×64 (одна строка page 6: STEP + BFO).
- Нет pixel-perfect сетки всех экранов.
- Меню configuration без иерархии (старые SETTINGS).
- Радио и UI ещё в одном ATS_EX.ino.

Flash / RAM (Uno)
- 31478 / 32256 flash, 1211 SRAM (после idle BFO).

Как пользоваться на железе
- Короткий клик энкодера: смена focus.
- Крутить: частота в NORMAL; STEP/VOL/BW/BFO в focus/transient.
- STEP/VOL/BW кнопки по-прежнему выбирают функцию.
- Длинный энкодер: seek только AM/FM.
