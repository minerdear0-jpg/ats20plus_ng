ATS-20Plus_next — журнал

Ветка: ATS-20Plus_next (локально, без push).
Baseline прошивки: 4fe59be (build.sh). Дальше: один эксперимент = один commit = один avr-size = один hardware test.
Железо цели: Arduino Uno, ATmega328P, 32256 flash / 2048 SRAM.

I2C (уже архитектура, не план): 100 kHz NORMAL/QUIET; 400 kHz только пакет commitRadioFrequency; патч SSB 500 kHz. История глобальных 400: 965c5d3, снято.
SSB: deadline 10 ms (`g_rfPendingSince`), не debounce. Фон (S-meter/SQL/RDS/battery) не на крутилке.
S-meter: frozen unless hardware test shows perceptual/RF problem.
Dirty = dirty-region (page 5), не dirty-pixel; смена val → весь ramp 114.
Опора: спецификации + ATS-20Plus_next_gaps.txt. UI: ATS-20_UI_state_machine.txt поверх Sweet Spot.

Сделано
- Encoder burst, ISR короткий, loop: input first.
- Deferred SI4735: AM/FM debounce 70 ms; SSB/CW deadline 10 ms; 400 kHz только на пакет commit.
- Нет delay() на крутилке и в seek-колбэке.
- RDS / S-метр / заряд не ходят по I2C, пока крутится encoder.
- Dirty mark/flush для частоты.
- Слои NORMAL / FOCUS / TRANSIENT. Press: STEP → VOL → BFO → MAIN. TRANSIENT press и timeout 1.2 с → MAIN.
- MENU: RADIO / DISP / AUDIO / SYS. BandDn вход/выход. Press войти/править. Long и BandUp = назад. AM/FM long = seek; SSB/CW long = MENU.
- S-метр page 5; secondary page 6 STEP/BW, page 7 BFO/VOL/charge.
- g_currentCmd (VOL/STEP/BW/BAND/MODE). g_sMeterOn и prev/prevFunc сняты.
- waitToSend: потолок ~50 ms / NACK (build.sh патчит PU2CLR). RADIO ERR, encoder press = retry.
- Первый battery sample больше не 0%.
- MODE: overlay, encoder ◀ mode ▶, не мгновенный цикл кнопкой.
- FM: ST по пилоту. USE_RDS 0.
- Splash v2.0b, (C) OOMAN / Cursor 2026.
- Шаг AM/SSB раздельный. EEPROM APP_VERSION 123.
- ANB, SQL (AM), DIS, CWP. build.sh → build/uno (не в git).
- Радио: radio.cpp C-функции, не класс. Draw в .ino.

Компромиссы
- Header: MODE + ST. VOL/BW на secondary, не в шапке.
- g_uiFocus + g_currentCmd + MENU — по-прежнему три измерения.
- Дублирование doFrequencyTune / TuneSSB дешевле DRY-слоя.
- RDS-категории в MENU нет. Pong не берём.
- P0.5 CLKPR 50%: код жив, на железе не проверено.

Flash / RAM
- После MENU (4fe59be): 31678 flash, SRAM 1272.
- После P0–P3 (этот срез): 31996 / 32256 flash (~99%), SRAM 1289 (~63%). Запас ~260 B.
- P0–P3 одним проходом кода (не 7 отдельных avr-size). Слух/NACK/CLKPR — hardware.

Дальше
P0.5 CLKPR 50% на железе (millis, I2C, 10/70/1200 ms).
Hardware: NACK/CTS timeout, RADIO ERR retry, MODE overlay, battery %, SSB secondary.
DROP acceleration, Mini GUI, framebuffer, S-meter pixel-diff.
g_uiFreqClean: uiMark(..., true) по-прежнему не вызывается.

Железо
- Короткий энкодер: STEP→VOL→BFO→MAIN. MENU: rotate список, press войти/править.
- MODE (не FM): overlay; крутилка меняет модуляцию; press/timeout → MAIN.
- BAND: overlay; крутилка сегменты.
- RADIO ERR: press энкодера или MODE = retry.
- Длинный энкодер: seek AM/FM; SSB/CW и в MENU — назад / открыть MENU.
