# ATS-20 Plus NG — руководство пользователя

Прошивка **ats20plus_ng** для приёмников **ATS-20 / ATS-20+** на **ATmega328** и **Si473x**.

**Версия:** 2.0C  
**Сборка:** `./build.sh 328pb` → `build/328pb/ATS_EX.ino.hex` (микрокод под реальный ATmega328PB; `./build.sh uno` — вариант под 328P)  
**Репозиторий:** https://github.com/minerdear0-jpg/ats20plus_ng  
**Скачать .hex:** https://github.com/minerdear0-jpg/ats20plus_ng/releases/tag/v2.0B

---

## Чем отличается от Goshante ATS_EX v1.18

Базовая логика радио (диапазоны, SSB+BFO, шаги, EEPROM) сохранена от **Goshante ATS_EX v1.18** (линия **PU2CLR**). Интерфейс и часть сервисов переработаны под **128×64 OLED** и лимит flash (~32 КБ).

| Область | Goshante v1.18 | ats20plus_ng |
|--------|----------------|--------------|
| **Экран** | Семисегментный шрифт Goshante, нижняя строка шаг/громкость | Частота **Icom-style 16×24**; idle-подписи **Karat 5×7**; overlay **TITLE …… [chip]** 8×16 |
| **S-метр** | Вкл/выкл длинным **STEP**; простая шкала | **Всегда на экране**; «стена» из **7 кубов** + подпись **GOST**; пиковая игла с аналоговым attack/release |
| **Индикатор после шкалы** | — | **SNR (dB)** на КВ AM/SSB; на FM/WFM **◀ STOP ▶** (подсказка подстройки частоты) |
| **Настройки** | Многостраничное **MENU** (**BAND−**), листание **BAND+** | **Пещера настроек**: **MODE** удержание → одна строка `ПАРАМ …… [значение]`; **MODE** короткое = следующий пункт |
| **RDS (FM)** | Включён, **MODE** короткое на FM | **Отключён в сборке** (`USE_RDS 0`) — освобождение flash |
| **Крутилка** | В основном частота; в MENU — навигация | Частота без задержки OLED; **клик энкодера** на SSB/CW: цикл **частота → STEP → VOL → BFO** |
| **AM/FM энкодер** | Скан (**Sca**) или STEP | **Короткий клик** = mute; **длинный** = seek по станциям |
| **AGC (кнопка)** | Длинное = **Sync SSB** | Длинное = **яркость (BRT)**; **Sync** — в пещере (**SYN**) |
| **I2C / отклик** | Частые обращения к SI4735/OLED в loop | **100 kHz** в работе; **400 kHz** только при commit частоты; отложенная подстройка (**70 ms** AM/FM, **10 ms** SSB) |
| **Ошибки радио** | — | Экран **RADIO ERR**; клик энкодера или **MODE** = повтор init |
| **CPU 50 %** | Работало через CLKPR | Слот **CPU** в EEPROM сохранён; **runtime CLKPR снят** (всегда 16 MHz) |

Диапазоны **LW / MW / SW / CB / FM**, плавный **SSB+BFO**, скан AM/FM, калибровка **BFO**, заряд батареи (**A2** + делитель) — как у Goshante, если не указано иное.

## Чем отличается от diqezit

В прошивке **diqezit** (ветка `ats20_ats_ex`, v7.x) взяты **сервисные** функции и стабильность железа, **не** их минималистичный UI.

| Область | diqezit | ats20plus_ng |
|--------|---------|--------------|
| **S-метр** | Тонкая полоска RSSI | **7-кубовая стена** + GOST-подпись S9/S9+ |
| **Шина I2C** | ~61,5 kHz базово; OLED часто на той же скорости | **100 kHz** idle; **400 kHz** только пакет commit частоты (не на каждый кадр OLED) |
| **Настройки** | Классическое меню | **Однострочная пещера** (MODE long) |
| **Новое из diqezit** | **ANB**, **SQL**, **DIS** (автовыключение OLED), **CWP** (pitch CW) | Включено в пещеру настроек |
| **RDS / Pong / лишнее** | RDS, игры, Active Command | **Не включено** (flash) |
| **FM подсказка** | — | **FREQOFF**: стрелки / STOP / поиск по SNR; **TUNED** после поимки |

## Прошивка и первый запуск

1. Определите плату: **Nano** (Arduino отдельной платой) или **Uno** (328 на одной плате). ATS-20+ обычно **Uno**, flash **32256** байт.
2. Скачайте из [релиза v2.0C](https://github.com/minerdear0-jpg/ats20plus_ng/releases/tag/v2.0C):
   - **`ats20plus_ng_v2.0C_usb.hex`** — прошивка **через USB** (Optiboot уже стоит на приёмнике);
   - **`ats20plus_ng_v2.0C_with_bootloader.hex`** — **приложение + bootloader** (ISP / USBasp);
   - файлы с суффиксом **`_328pb`** — микрокод под реальный **ATmega328PB** (ISP-сигнатура `1E 95 16`); на PB-плате берите их.
3. Или соберите сами: `./build.sh 328pb` (или `./build.sh uno` под 328P).
4. **Сброс EEPROM:** удерживайте **кнопку энкодера** при включении → **EEPROM RESET**.

При проблемах с USB используйте порт **USB 3.0**, включайте приёмник **до** подключения кабеля.

### Модификация индикатора батареи

Два резистора **10 кΩ**: один на GND, второй на **+** АКБ; середина → **A2**. Прошивка сама определит делитель и покажет **%** заряда.

## Экран

```
[MODE]     [BW]              [TUNED]
        14.256.000
S9+  ████████▌  [12]     ← SNR dB на КВ или ◀/STOP/▶ на FM
              MHz
```

- **MODE** (слева): AM / LSB / USB / CW / **WFM** на FM; при mute на AM/FM — **MUTE** (plain Karat, без заливки).
- **BW** (центр): ширина полосы (`AUTO`, `3.0K`, `110K` …). При **TUNED** сдвигается на 8 px влево.
- **TUNED** (справа): FM поймана после **STOP**; гаснет при сдвиге частоты.
- **Частота:** крупные цифры; на FM и SSB — дробная часть.
- **S-метр:** 7 сегментов «стены»; подпись **S-метра GOST** (plain, без chip).
- **Универсальный индикатор** (после стены): на **КВ AM/SSB** — **SNR в dB**; на **WFM/AM (не КВ)** — **◀ STOP ▶** для подстройки; иначе пусто.
- **Стерео FM:** пиктограмма `((·))` над **MHz**, пока есть пилот (без мигания).

Overlay (STEP, VOL, BW, MODE, BAND, BFO, BRT): одна строка **16 px**:

```
TITLE ............... [VALUE]
```

Крутилка меняет только **[VALUE]**. Через **2 с** бездействия — две вспышки заливки (**250 ms**), затем применение и скрытие. **Клик энкодера** — сразу подтвердить.

## Кнопки

### BAND+ (диапазон вверх)
- **Короткое:** overlay **BAND**; крутилка — следующий/предыдущий диапазон.
- **Удержание:** быстрый переход диапазонов вперёд (на КВ — по поддиапазонам).

### BAND−
- **Короткое:** закрыть текущий overlay / выйти из transient.
- **Удержание:** быстрый переход диапазонов назад.

> Многостраничного **MENU** через **BAND−** больше нет.

### VOL+
- **Короткое:** overlay **VOL**; крутилка — громкость 0…63.
- **Удержание:** быстрое увеличение громкости.

### VOL−
- **Короткое:** **mute** / unmute.
- **Удержание:** быстрое уменьшение громкости.

### STEP
- **Короткое:** overlay **STEP** (шаг частоты).
- **Длинное:** принудительное обновление S-метра (шкала и так всегда видна).

### BW
- **Короткое:** overlay **BW** (не в **CW**).

### MODE
- **Короткое (не FM):** overlay **MODE** — смена AM / LSB / USB / CW; крутилка листает модуляции.
- **Короткое (FM):** подтверждение overlay (RDS в этой сборке **нет**).
- **Короткое в пещере настроек:** следующий параметр (**TITLE** меняется, chip — значение).
- **Длинное:** войти / выйти из **пещеры настроек** (кольцо параметров).
- При **RADIO ERR:** короткое = повтор инициализации радио.

### AGC (Display)
- **Короткое:** вкл/выкл **дисплея** (радио продолжает работать).
- **Длинное:** overlay **BRT** (яркость **SCR**).

### Энкодер — вращение
- **Обычный режим:** частота (шаг снизу / в overlay STEP).
- **Overlay / пещера:** изменение значения в chip.
- **Overlay BAND:** смена диапазона.
- **Overlay MODE:** смена модуляции.
- **SSB, фокус BFO** (после клика): подстройка BFO.

### Энкодер — клик
- **RADIO ERR:** retry.
- **Любой overlay:** подтвердить и закрыть.
- **AM / FM:** mute toggle.
- **SSB / CW / AM (не overlay):** цикл фокуса **частота → STEP → VOL → BFO** (BFO только на SSB).

### Энкодер — длинное
- **AM / FM:** **seek** станций (если не в mute — с mute seek не стартует; длинное с mute снимает mute).
- **Иначе:** закрыть overlay.

## Пещера настроек (MODE — удержание)

Одна строка, без полноэкранного меню. Кольцо из **18** пунктов; недоступные для текущей модуляции **пропускаются**.

| Код | Параметр | Описание |
|-----|----------|----------|
| **ATT** | Аттенюатор | **AUT** или 1…37 |
| **ANB** | Auto Noise Blanker | Off / On |
| **SQL** | Squelch | 0…60 (0 = выкл) |
| **SYN** | Sync SSB | Off / On |
| **COF** | SSB Cutoff Filter | Off / On / **AUT** |
| **AVC** | AVC | 12…90 |
| **SM** | Soft Mute | 0…32 |
| **DEE** | De-emphasis FM | 50 / 75 µs (только **WFM**) |
| **SVC** | AVC для SSB | Off / On |
| **SSM** | SSB Soft Mute | **RSS** / **SNR** |
| **SCR** | Яркость | 5…125 |
| **DIS** | Автовыключение OLED | 0 = нет; 1…4 = **15 / 30 / 60 / 120 с** |
| **SW** | Единицы на КВ (AM) | KHz / MHz |
| **UNI** | Показ единиц частоты | Off / On |
| **BFO** | Калибровка BFO | −60…+60 (×0,01 kHz) |
| **SCA** | Скан на клик энкодера | Off / On (AM/FM) |
| **CW** | Сторона CW | LSB / USB |
| **CWP** | Pitch CW | 5…8 (×100 Hz) |

- **Крутилка** — изменить значение в chip.
- **MODE короткое** — следующий **TITLE**.
- **Клик энкодера** или **6 с** бездействия — выход, **сохранение в EEPROM**.
- **BAND−** в пещеру **не** входит.

## FM: подсказка частоты (FREQOFF) и TUNED

На **WFM** (и AM вне КВ) в слоте после S-метра:

- **◀ / ▶** — частота смещена; крутилка подстраивает.
- **STOP** — близко к центру несущей (|offset| ≤ 12 kHz, валидный сигнал).
- **Далеко** (|offset| ≥ 120 kHz): поиск по **SNR** с энкодером; разворот после двух ухудшений.

После **STOP** появляется idle **TUNED** справа до смены частоты.

## Диапазоны и шаги

- **LW:** 153…520 kHz  
- **MW:** 520…1710 kHz  
- **SW:** 1710…30000 kHz (единый «большой» КВ, поддиапазоны не режут шаг)  
- **CB:** внутри SW  
- **FM:** 64…108 MHz (**WFM**)

**Шаги:** AM — 1/5/9/10/50/100k/1M; SSB — 1/5/9/10k и 10/25/50/100/500 Hz; FM — 10k/100k/1M.

**BFO** на SSB входит в общую частоту и шаг; отдельный overlay **BFO** — через фокус энкодера.

---

## Ограничения

- Flash **~99 %** (≈32 КБ). Новые крупные функции без вырезания чего-то ещё **не поместятся**.
- **RDS** в этой сборке **отключён**.
- **CPU 50 %** в EEPROM не меняет частоту — только сохранение слота.
- Bootloader **не удаляется**.

## Сборка из исходников

```bash
./build.sh uno          # полная сборка → build/uno/
./build.sh --fast uno   # инкрементально
./build.sh --upload uno # USB avrdude (328P Optiboot 115200)
```

Железо ATS-20+: кремний **ATmega328PB**; USB-bootloader отвечает как **328P**.
